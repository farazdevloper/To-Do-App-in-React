React To-Do List App (LocalStorage)

A modern and beginner-friendly React To-Do List application built using React Hooks and LocalStorage. This app allows users to add, complete, and delete tasks, and keeps data saved even after refreshing the browser.

This project is perfect for React beginners who want to understand useState, useEffect, component structure, and LocalStorage usage.

🚀 Features

✅ Add new tasks

✅ Mark tasks as completed

✅ Delete tasks

✅ Tasks saved in LocalStorage

✅ Data remains after page refresh

✅ Clean & modern UI using Tailwind CSS

✅ Fully responsive design

🛠️ Tech Stack

React JS

React Hooks (useState, useEffect)

Tailwind CSS

JavaScript (ES6)

LocalStorage

Vite / CRA (depending on your setup)

⚙️ How It Works

Tasks are stored in LocalStorage

On app load, tasks are fetched from LocalStorage

Any change in tasks automatically updates LocalStorage

Each task has:

id

title

completed status

📦 Installation & Setup

Clone the repository

git clone https://github.com/farazdevloper/To-Do-App-in-React.git


Go to project folder

cd react-todo-list


Install dependencies

npm install


Run the project

npm run dev

🖥️ Usage

Type your task in the input field

Click Add + button

Click on task to mark it complete

Delete tasks when not needed

Refresh the page — tasks stay saved ✔️
